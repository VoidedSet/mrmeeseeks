# Walkthrough — Sentinel Observability Layer

We have successfully implemented **Sentinel**, a high-performance C++ Linux Observability Layer, and integrated it cleanly into the Mr. Meeseeks Python async pipeline via a Unix Domain Socket (UDS).

---

## Changes Made

### 1. Sentinel Daemon (C++)
- **CMake Build Pipeline**: Implemented a modern CMake build setting standard explicitly to C++17 (`CMakeLists.txt`).
- **Thread-safe Bounded Event Queue**: Designed a thread-safeBoundedEventQueue in C++ (`queue.h`) to handle event logging between collector threads. It implements a drop-oldest policy capped at 10,000 events to prevent memory exhaustion (OOM).
- **Process Event Collector (`collectors/process_collector.cpp`)**: Leverages Linux Netlink Process Connectors (`PROC_CN_MCAST_LISTEN`) to receive real-time fork, exec, and exit notifications from the kernel. It resolves starting processes using `/proc/<pid>/comm` and ignores kernel tasks (PIDs < 100), ensuring zero-polling overhead.
- **Filesystem Event Watcher (`collectors/inotify_collector.cpp`)**: Implements recursive watcher registration, dynamic subdirectory tracking, and cookie-based move pairing (50ms timeout) to group rename operations into clean `FILE_MOVED` events.
- **Network Interface Monitor (`collectors/network_collector.cpp`)**: Subscribes to `NETLINK_ROUTE` multicast groups (`RTMGRP_LINK` | `RTMGRP_IPV4_IFADDR`) to track link status (UP/DOWN) and IP allocation.
- **Device Monitor (`collectors/device_collector.cpp`)**: Connects to `libudev` netlink streams to identify when external drives or USB hardware are connected/disconnected.
- **UDS Socket Client & Reconnect Logic (`main.cpp`)**: Streams newline-terminated JSON payloads to `/tmp/meeseeks_sentinel.sock` using `nlohmann/json`. Includes reconnection retries with exponential backoff to handle startup race conditions. Setups thread-safe signal cleanup via `std::atomic<bool>`.

### 2. Python Socket Listener & Supervisor (`kernel/sentinel_listener.py`)
- Starts an async Unix Domain Socket server at `/tmp/meeseeks_sentinel.sock` at startup.
- Spawns the compiled `sentinel-daemon` binary as a child subprocess.
- Logs stdout/stderr logs from the C++ daemon natively in Python logs.
- Supervises the child process: restarts the daemon within 2 seconds if it exits or crashes.
- Dispatches parsed JSON events asynchronously to `brain.handle_proactive_event()`.

### 3. Integrated startup lifecycle (`kernel/kernel_listener.py`)
- Wrapped the polling loops inside a try-finally context that initializes the `SentinelListener` at boot and cleanly halts/unlinks UDS files on close.
